## 🚀 Featured Projects

### 🤖 Agentic Enterprise Intelligence Platform

An AI-powered enterprise intelligence platform designed to automate research, information retrieval, and data-driven workflows through agentic systems.

**Tech Stack:** Python, FastAPI, LangGraph, MCP, PostgreSQL, pgvector, React

- Built a multi-agent architecture using LangGraph with Supervisor-Planner orchestration, autonomous research agents, and critic verification loops.
- Developed hybrid RAG and SQL pipelines using pgvector and AST-validated PostgreSQL queries with deterministic citation checks.
- Integrated modular MCP tools, guardrails, and LangSmith tracing for reliable agent execution.
- Implemented real-time execution streaming to a React frontend using Server-Sent Events (SSE).

[![GitHub](https://img.shields.io/badge/View_Project-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/Div965yansh/agentic-enterprise-intelligence)

### 🏥 Healthcare AI Assistant

An intelligent clinical documentation assistant combining LLMs, Retrieval-Augmented Generation, and workflow orchestration to streamline clinical documentation.

**Tech Stack:** Python, FastAPI, LangGraph, Ollama, PostgreSQL, pgvector, React

- Built an end-to-end application for clinical conversation processing, automated documentation, and encounter management.
- Designed LangGraph workflows for clinical information extraction, query formation, and retrieval.
- Implemented RAG using Sentence Transformers and PostgreSQL with pgvector for semantic retrieval.
- Integrated Faster Whisper for audio transcription and developed patient history management functionality.
- Developed REST APIs connecting backend services with a React frontend.

[![GitHub](https://img.shields.io/badge/View_Project-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/Div965yansh/Healthcare-ai-assistant)

### 📄 AI Document Intelligence Platform

An end-to-end document intelligence application supporting document classification, OCR, information retrieval, and question answering across multiple file formats.

**Tech Stack:** Python, PyTorch, Transformers, DistilBERT, EasyOCR, OpenCV, Flask, React

- Fine-tuned DistilBERT on the AG News dataset containing 120K news articles across four categories.
- Built document processing pipelines supporting PDF, DOCX, TXT, and image inputs.
- Implemented OCR with OpenCV preprocessing for extracting text from scanned documents.
- Developed an end-to-end retrieval pipeline covering text extraction, chunking, embeddings, semantic search, and question answering.
- Built REST APIs and an interactive React frontend.

[![GitHub](https://img.shields.io/badge/View_Project-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/Div965yansh/docu-query)
